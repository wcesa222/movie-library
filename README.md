# 电影资料库（课程实验第 15 题）

这是一个使用 Markdown、CSV、HTML、CSS、JavaScript 和 Python 标准库完成的电影资料库项目。

## 项目用途

- `README.md`：说明项目用途、文件结构和实验步骤。
- `movies.csv`：保存结构化电影数据，是网页唯一的数据源。
- `index.html`：提供网页结构。
- `styles.css`：提供现代化响应式界面。
- `app.js`：读取 CSV、渲染卡片，并实现搜索和排序。
- `server.py`：使用 Python 标准库启动本地 HTTP 服务器，并禁止缓存 CSV。

网页不会把电影数据写死在 HTML 中。修改 `movies.csv` 后刷新网页，即可看到最新数据。

## 功能

1. 从 CSV 动态加载电影数据。
2. 以响应式卡片展示名称、导演、年份、类型和评分。
3. 支持按电影名称、导演和类型实时搜索。
4. 支持按评分、年份和名称排序。
5. 显示当前筛选结果数量、平均评分和最近加载时间。
6. 提供“重新加载 CSV”按钮。
7. 浏览器请求和服务器响应均禁用缓存，便于验证数据同步。

## 运行方法

在本项目目录打开终端，执行：

```bash
python server.py
```

然后访问：

```text
http://localhost:8000
```

如需更换端口：

```bash
python server.py 8080
```

按 `Ctrl+C` 停止服务器。

> 不要直接双击 `index.html`。浏览器通常不允许 `file://` 页面读取本地 CSV，应通过 `server.py` 访问。

## 修改 CSV

使用文本编辑器或电子表格软件打开 `movies.csv`。文件表头必须保持为：

```csv
电影名称,导演,上映年份,类型,评分
```

新增电影时，每行填写一部电影。例如：

```csv
星际穿越,克里斯托弗·诺兰,2014,科幻,9.4
```

如果字段中包含英文逗号，应使用英文双引号包围整个字段。

## 验证 CSV 与网页同步

1. 启动服务器并打开网页，记录电影总数。
2. 在 `movies.csv` 末尾新增一部电影，或修改某部电影的评分。
3. 保存 CSV。
4. 返回网页，点击“重新加载 CSV”或刷新页面。
5. 搜索新增电影，确认名称、评分等信息已经出现。
6. 整个过程中不需要修改 `index.html` 或 `app.js`。
